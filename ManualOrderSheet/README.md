# ManualOrderSheet (수기운용지시서 자동 생성)

권리배정내역 엑셀을 읽어 **수기운용지시서(.docx)** 를 자동으로 만든다.
출력은 파일 생성까지만 하고, 메일 발송은 하지 않는다.

## 폴더 구조

```
ManualOrderSheet/
├── run.py                        # 실행 진입점
├── requirements.txt
├── src/
│   ├── config.py                 # 회사/담당자/계좌/거래유형 등 고정값  ← 주로 여기만 수정
│   ├── reader.py                 # 권리배정내역 엑셀 파싱
│   ├── instruction.py            # 지시서 단위 그룹핑 + 문구 생성
│   ├── writer.py                 # 템플릿에 값 채워 .docx 저장
│   ├── docx_util.py              # python-docx 보조 함수
│   ├── pdf.py                    # Word 로 PDF 변환 + 전체 이미지화
│   ├── seal.py                   # 사용인감 갱신/제거
│   ├── share.py                  # 공유 드라이브 사본
│   └── build_template.py         # 원본 지시서 → 자리표시자 템플릿 변환
├── templates/
│   ├── 수기운용지시서_배당지급_template.docx   # ← 실제로 쓰는 템플릿
│   ├── 수기운용지시서_단주대금_template.docx   # ← 실제로 쓰는 템플릿
│   ├── 20260825_...차입주식배당지급.docx       # 원본(수기 작성분)
│   └── 20260901_...차입주식단주대금지급.docx   # 원본(수기 작성분)
└── data/
    ├── input/YYYYMMDD/           # 권리배정내역 엑셀
    └── output/YYYYMMDD/          # 생성된 지시서 (지급일 기준 하위 폴더)
```

## 설치

Python 3.9 이상.

```
pip install -r requirements.txt
```

## 사용법

```
python run.py                                           # data/input 의 최신 날짜 폴더 (인자 없이 실행)
python run.py 20260825                                  # data/input/20260825 폴더 전체
python run.py data/input/20260825/권리배정내역_xxx.xls    # 파일 하나만
python run.py 20260825 -o D:/공유/지시서 --seq 3          # 출력 폴더 / 문서번호 시작번호 지정
```

주요 옵션

| 옵션 | 설명 |
|---|---|
| `-o, --output` | 출력 폴더 (기본 `data/output`) |
| `-t, --template` | 다른 템플릿 사용 |
| `--seq` | 문서번호 일련번호 시작값 (기본 1 → `제20260825-01`) |
| `--no-overwrite` | 같은 이름 파일이 있으면 `(2)` 를 붙여 저장 |
| `--flat` | 날짜 하위 폴더 없이 출력 폴더에 바로 저장 |
| `--dry-run` | 공유 드라이브에 실제로 쓰지 않고 복사 계획만 출력 |
| `--no-shared` | 공유 드라이브 사본 저장 생략 (로컬만) |
| `--shared-dir` | 공유 드라이브 경로 변경 |
| `--overwrite-shared` | 공유 폴더의 기존 동일 이름 파일을 덮어씀 |
| `--no-seal` | 사용인감 없이 `(인)` 만 남김 (초안용) |
| `--no-pdf` | PDF 를 만들지 않음 (docx 만) |
| `--keep-text-pdf` | 이미지 PDF 외에 텍스트 PDF(`.pdf`)도 남김 |
| `--pdf-dpi` | 이미지 PDF 해상도 (기본 288) |

출력은 기본적으로 `<출력폴더>/<지급일 YYYYMMDD>/` 아래에 저장된다 (입력 폴더와 같은 구조).
항상 한 폴더에 모으고 싶으면 `--flat` 을 쓰거나 `config.OUTPUT_SUBDIR_BY_DATE = False` 로 바꾼다.

## 사용인감

도장은 템플릿의 서명부 문단('주식회사 두나미스자산운용')에 떠 있는(anchor) 그림으로
들어 있고, `(인)` 글자 위에 겹쳐 찍힌다. 위치·크기는 원본 지시서의 값을 그대로 쓴다.

- 실행할 때 `config.SEAL_IMAGE`(= 공유 폴더의 `사용인감도장1.png`) 내용으로 이미지를
  갱신하므로, 인감 파일을 교체하면 다음 실행부터 자동 반영된다.
- 원본 PNG 를 못 찾으면(드라이브 미연결) 템플릿에 들어 있는 이미지를 그대로 쓴다.
- 도장 없는 초안이 필요하면 `--no-seal` (또는 `config.INSERT_SEAL = False`).

**위치를 바꾸려면** 워드에서 `templates/수기운용지시서_template.docx` 의 도장 그림을
드래그해 옮기고 저장하면 된다. 코드는 위치를 건드리지 않는다.

> 주의: `python-docx` 로 문단 텍스트를 바꾸면 그 문단 안의 그림이 함께 지워진다.
> `docx_util.set_paragraph_text()` 가 그림 요소를 떼어놨다 다시 붙여 이를 막는다.
> 문단 조작 코드를 새로 쓸 때는 반드시 이 함수를 쓴다.

## PDF 생성

docx 를 만든 뒤 Word 로 PDF 로 변환하고, 그 PDF 를 **페이지 전체 이미지로 다시 구워서**
`_E.pdf` 로 저장한다. 텍스트 레이어가 없으므로 글자 선택·복사가 되지 않고, 인감도
페이지 이미지의 일부라 따로 빼낼 수 없다. 기존 공문의 `_E.pdf` 와 같은 방식이다.

- 해상도 288dpi (A4 2382x3368px) — 기존 공문과 동일. `config.PDF_DPI` 로 변경.
- Word 작성자·파일경로 등 PDF 메타데이터는 지운다.
- 텍스트 PDF 도 함께 남기려면 `--keep-text-pdf`. **이 파일은 인감을 빼낼 수 있으니 주의.**
- PDF 없이 docx 만 만들려면 `--no-pdf`.
- Word(pywin32)를 못 쓰면 경고만 남기고 docx 는 정상 생성된다.

### 한 장 맞추기

내역 줄이 늘어나면 서명부가 다음 장으로 밀린다. 표 아래 빈 줄을 **필요한 만큼만**
걷어내 한 장에 유지한다. 몇 개를 걷어낼지는 임시 파일을 만들어 Word 로 실제 페이지
수를 재서 결정하므로, 줄 수와 무관하게 항상 맞는다. 빈 줄을 다 걷어내도 한 장에
담기지 않으면 경고가 뜬다 (그때는 템플릿의 표 글자 크기·여백을 조정한다).

Word 를 못 쓰는 환경에서는 어림값(늘어난 줄 수 - 1)을 쓴다.

## 공유 드라이브 사본

로컬 저장 후 `Z:.펀드.수탁사(수기운용지시공문)` 에도 사본을 남긴다
(경로는 `config.SHARED_OUTPUT_DIR`, 끄려면 `None` 으로).

기존 정리 방식을 그대로 따른다.

```
Z:.펀드.수탁사(수기운용지시공문)└── 20260828_차입주식배당지급    ├── 20260828_두나미스자산운용 수기운용지시서_기업수탁_차입주식배당지급.docx
    ├── 20260828_두나미스자산운용 수기운용지시서_기업수탁_차입주식배당지급_E.pdf
    ├── 20260828_두나미스자산운용 수기운용지시서_신한수탁_차입주식배당지급.docx
    ├── 20260828_두나미스자산운용 수기운용지시서_신한수탁_차입주식배당지급_E.pdf
    └── 권리배정내역_20260827133506.xls        # 원본 엑셀 사본
```

안전장치 두 개가 걸려 있다.

- **기존 파일은 덮어쓰지 않는다.** 같은 이름이 있으면 `건너뜀(이미 있음)` 으로 넘어간다.
  서명·수정된 실제 공문이나 PDF 를 날리지 않기 위한 것. 정말 갱신해야 하면
  `--overwrite-shared` 를 붙이거나 공유 폴더에서 기존 파일을 먼저 치운다.
- **폴더명 띄어쓰기 차이를 흡수한다.** 같은 날짜·같은 거래유형의 폴더가 이미 있으면
  (예: `20260825_차입주식 배당지급`) 새로 만들지 않고 그 폴더를 쓴다.

드라이브가 연결돼 있지 않으면 경고만 남기고 로컬 저장은 정상 처리된다.
실제로 뭐가 복사될지 미리 보려면 `--dry-run` 을 쓴다.

```
python run.py 20260828 --dry-run
```

## 문서 종류

권리배정내역 엑셀 하나에서 **두 종류**의 지시서가 나온다. 한 파일에 둘 다 들어 있으면
둘 다 만들고, 문서번호는 지급일 기준으로 이어서 매긴다(예: 2026-04-17 → -01 ~ -04).

| 종류 | 대상 행 | 내역 표 | 템플릿 |
|---|---|---|---|
| 배당지급 | `대금` > 0 | 구분·해당 펀드·반영일자·**대차수량**·금액·거래유형명 | `수기운용지시서_배당지급_template.docx` |
| 단주대금 | `단주대금` > 0 | 구분·해당 펀드·반영일자·**지급금액**·거래유형명 | `수기운용지시서_단주대금_template.docx` |

- **배당지급**은 현금배당으로 원소유주에게 지급할 배당금.
- **단주대금**은 주식배당·회사분할 등으로 차입주식에 배정이 생겼을 때, 1주 미만
  단수주에 해당하는 현금을 원소유주에게 지급하는 건. 권리구분(주식배당/회사분할)과
  무관하게 문구가 같으므로 `config.ODD_LOT_TRADE_NAMES` 는 (운용구분, 증권구분) 만 본다.
  종목명은 `기준종목명` 이 아니라 **배정받은 종목명**(`권리배정내역 > 종목명`)을 쓴다.

### 표 작성 규칙

- 정렬: **종목명 → 펀드코드** 순.
- **해당 펀드 / 반영일자 / 거래유형명**은 윗줄과 같으면 비워둔다.
- 한 문서 안에서 (펀드, 종목, 단가) 가 같은 행은 합산한다.

## 엑셀 → 지시서 매핑

| 지시서 항목 | 출처 |
|---|---|
| 문서번호 `제YYYYMMDD-NN` | 지급일 + 일련번호 |
| 문서 일자 / 반영일자 / 제목의 날짜 | `지급일` |
| 수신 `○○은행 수탁부 귀하` | `수탁기관명` 의 괄호 안 뒷부분 |
| 참조 `○○증권 PBS` | `수탁기관명` 의 괄호 앞부분 |
| 수취계좌 | `중개기관명` → `config.RECEIVE_ACCOUNTS` |
| 해당 펀드 | `펀드명 (펀드코드)` |
| 대차수량 / 금액 | `대차수량`, `대금` 합계 |
| 거래유형명 | (`운용구분`, `권리구분`, `증권구분`) → `config.TRADE_TYPE_NAMES` |
| 종목명 / 주당금액 | `기준종목명`, `대금 ÷ 대차수량` |

**문서 분리 기준**: (지급일, 수탁기관, 거래유형) 이 다르면 별도 파일로 생성한다.
**행 합산 기준**: 같은 문서 안에서 (펀드, 종목, 주당금액) 이 같으면 한 줄로 합산한다.

## 값이 등록되어 있지 않을 때 (중요)

- 새 중개기관 → 콘솔에 `[경고] 수취계좌 미등록` 이 뜨고 문서에 `[[수취계좌 미등록: ...]]` 로 박힌다.
  `config.RECEIVE_ACCOUNTS` 에 계좌를 추가한다.
- 새 거래유형 → **문서를 만들지 않고 건너뛴다.** 임의로 문구를 지어내면 잘못된 공문이
  그대로 나갈 수 있어서다. 실행 끝에 `[중단] 등록되지 않은 거래유형` 블록으로 알려주므로
  `config.TRADE_TYPE_NAMES` (배당) 또는 `ODD_LOT_TRADE_NAMES` (단주대금) 에 문구를 추가한다.
- 수탁기관명이 `PBS명(운용사-수탁은행)` 형식이 아니면 `config.TRUSTEE_OVERRIDES` 에 등록한다.

## 양식(레이아웃)을 바꾸고 싶을 때

1. `templates/수기운용지시서_template.docx` 를 워드에서 직접 수정한다.
   `{{DOC_NO}}`, `{{FUND}}` 같은 자리표시자는 그대로 두면 된다.
2. 표 구조를 크게 바꿨거나 새 원본에서 다시 만들려면:

```
python -m src.build_template                      # 두 종류 모두
python -m src.build_template odd_lot              # 단주대금만
python -m src.build_template dividend "templates/새원본.docx"
```

### 자리표시자 목록

`{{CONTACT_NAME}}` `{{CONTACT_PHONE}}` `{{DOC_NO_PREFIX}}` `{{DOC_NO}}` `{{DOC_DATE}}`
`{{RECIPIENT}}` `{{CC}}` `{{SUBJECT}}` `{{TRADE_TYPE}}` `{{ORDER_DATE_KR}}`
`{{RECEIVE_ACCOUNT}}` `{{TOTAL_AMOUNT}}` `{{COMPANY_NAME}}` `{{CEO_NAME}}`

내역 표 반복 행(표 2의 2번째 행)에만 쓰는 값:
`{{NO}}` `{{FUND}}` `{{APPLY_DATE}}` `{{QTY}}` `{{AMOUNT}}` `{{TRADE_NAME}}` `{{TRADE_DETAIL}}`

## 알아둘 점

- 생성된 문서는 **검토 후 서명·발송**한다.
- 본문의 "수취계좌" 는 차입주식 배당금을 지급할 상대방(한국예탁결제원) 계좌다.
- 현재 검증된 거래유형은 `차입 / 현금배당 / 주식` 하나뿐이다. 그 외 유형(예: 대여)이 들어오면
  `[경고] 거래유형명 미등록` 이 뜨고 임시 문구로 표기되므로, 그때 실제 문구를 확인해
  `config.TRADE_TYPE_NAMES` 에 추가한다.
- 지금 검증된 입력은 KSD 권리배정내역(현금배당) 뿐이다. 다른 양식의 엑셀이 들어오면
  `reader.py` 의 컬럼명 매핑을 확인한다.
